# Департамент odoo.com

Концепція окремого контуру доставки: команда працює тільки з базами на Odoo Online, без
кастомних модулів. Аналітик проєктує й приймає, конфігурацію виконує Claude через зовнішній API.

Стадія — **проєктування**. Пілоту ще не було, усі цифри економіки є допущеннями, крім
зафіксованих ставок.

## З чого почати читання

1. **`CLAUDE.md`** — контекст для робочої сесії: що вирішено, які межі не можна порушувати,
   як працювати з прайсом
2. **`docs/рішення.md`** — журнал рішень із логікою: що прибирали зі скоупу і чому
3. **`docs/аудит-стенд-odoo19.md`** — що звірено з живим стендом Odoo 19 і які обіцянки
   виправлено
4. **`docs/відкриті-питання.md`** — що ще не вирішено, за впливом на рішення

## Файли

| Шлях | Що це |
|---|---|
| `data/price.json` | **джерело правди** для прайсу: 7 груп, 26 позицій, 3 рівні складності, 343 пункти складу робіт |
| `tools/build_calculator.py` | вшиває `price.json` у калькулятор, перевіряє структуру |
| `artifacts/concept.html` | концепція, 10 вкладок |
| `artifacts/calculator.html` | калькулятор для сейла (згенерований зі `price.json`) |

Обидва HTML — фрагменти для публікації через Artifact, без `<!doctype>` і `<head>`.

## Робота з прайсом

```bash
# правиш data/price.json, далі:
python3 tools/build_calculator.py
```

Ціна = `години_вручну × 50 €`, округлення до 50. Рівні вкладені: кожен наступний містить усе
з попереднього.
