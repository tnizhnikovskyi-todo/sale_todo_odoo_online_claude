# План збірки — ТОВ «Приклад»

Куплено: База р.1
Кроків до виконання: 31

Виконує Claude через зовнішнє API. Після КОЖНОГО кроку, що змінює базу,
перечитати запис: конектор повідомляє помилку й тоді, коли дія відбулася.

## База р.1 · компанія з реквізитами

1. **знайти** `res.country` домен `[["code", "=", "UA"]]` → назвати `$країна`
2. **перевірити** `res.company` домен `[["parent_id", "=", false]]`
   - очікувати щонайменше: 1
3. **знайти** `res.company` домен `[["id", "=", 1]]` → назвати `$компанія`
4. **записати** `res.company` → ціль `$компанія`
   - значення: `{"name": "ТОВ «Приклад»", "street": "вул. Прикладна, 1", "city": "Київ", "zip": "01001", "country_id": "$країна", "phone": "+380000000000", "email": "office@example.com", "website": "https://example.com", "vat": "UA000000000000", "company_registry": "00000000"}`
5. **перевірити** `res.company` → ціль `$компанія`
   - очікувати: `{"name": "ТОВ «Приклад»", "company_registry": "00000000"}`

## База р.1 · українська мова інтерфейсу, часовий пояс і валюта UAH

6. **знайти** `res.lang` домен `[["code", "=", "uk_UA"]]` → назвати `$мова`
7. **записати** `res.lang` → ціль `$мова`
   - значення: `{"active": true}`
8. **знайти** `res.currency` домен `[["name", "=", "UAH"]]` → назвати `$валюта`
9. **записати** `res.currency` → ціль `$валюта`
   - значення: `{"active": true}`
10. **знайти** `res.company` домен `[["id", "=", 1]]` → назвати `$компанія`
11. **записати** `res.company` → ціль `$компанія`
   - значення: `{"currency_id": "$валюта"}`
12. **знайти** `res.users` домен `[["share", "=", false]]` → назвати `$внутрішні_користувачі`
13. **записати** `res.users` → ціль `$внутрішні_користувачі`
   - значення: `{"lang": "uk_UA", "tz": "Europe/Kiev"}`
14. **перевірити** `res.company` → ціль `$компанія`
   - очікувати: `{"currency_id": "$валюта"}`

## База р.1 · користувачі та групи доступу

15. **знайти_xmlid** → назвати `$група_внутрішній`
   - зовнішній id: `base.group_user`
16. **знайти_xmlid** → назвати `$група_продажі_свої`
   - зовнішній id: `sales_team.group_sale_salesman`
17. **знайти** `res.users` домен `[["login", "in", ["sales1@example.com", "sales2@example.com"]]]` → назвати `$продавці`
18. **записати** `res.users` → ціль `$продавці`
   - значення: `{"group_ids": [[4, "$група_продажі_свої"]]}`
19. **перевірити** `res.users` → ціль `$продавці`
   - очікувати_містить: `{"group_ids": "$група_продажі_свої"}`

## База р.1 · довідник контрагентів

20. **створити** `res.partner.category` (тільки якщо немає `[["name", "=", "Клієнт"]]`) → назвати `$тег_клієнт`
   - значення: `{"name": "Клієнт"}`
21. **створити** `res.partner.category` (тільки якщо немає `[["name", "=", "Постачальник"]]`) → назвати `$тег_постачальник`
   - значення: `{"name": "Постачальник"}`
22. **перевірити** `res.partner.category` домен `[["name", "in", ["Клієнт", "Постачальник"]]]`
   - очікувати кількість: 2

## База р.1 · нумерація документів: префікс, рік, лічильник

27. **знайти** `ir.sequence` домен `[["code", "=", "sale.order"]]` → назвати `$послідовність_замовлень`
28. **записати** `ir.sequence` → ціль `$послідовність_замовлень`
   - значення: `{"prefix": "ЗАМ/%(range_year)s/", "padding": 5, "use_date_range": true}`
29. **перевірити** `ir.sequence` → ціль `$послідовність_замовлень`
   - очікувати: `{"use_date_range": true, "padding": 5}`

## База р.1 · двофакторна автентифікація для адміністраторів
