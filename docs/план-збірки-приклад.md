# План збірки — ТОВ «Приклад»

Куплено: База р.1, Рахунки та оплати р.1, Проєкти й таймшити р.1
Кроків до виконання: 72

Виконує Claude через зовнішнє API. Після КОЖНОГО кроку, що змінює базу,
перечитати запис: конектор повідомляє помилку й тоді, коли дія відбулася.

## База р.1 · компанія з реквізитами

1. **знайти** `res.country` домен `[["code", "=", "UA"]]` → назвати `$країна`
2. **перевірити** `res.company` домен `[["parent_id", "=", false]]`
   - очікувати щонайменше: 1
3. **знайти** `res.company` домен `[["id", "=", 1]]` → назвати `$компанія`
4. **записати** `res.company` → ціль `$компанія`
   - значення: `{"name": "ТОВ «Приклад»", "street": "вул. Прикладна, 1", "city": "Київ", "zip": "01001", "country_id": "$країна", "phone": "+380000000000", "email": "office@example.com", "website": "https://example.com", "vat": "UA000000000000", "company_registry": "00000000"}`
5. **перевірити** `res.company` → ціль `$компанія`
   - очікувати: `{"name": "ТОВ «Приклад»", "company_registry": "00000000"}`
