# Звіт перевірки прайсу на стенді — 03.09.2026

Виконано за `docs/інструкція-перевірки-стенда.md`. Стенд: `edu-test-oca.odoo.com`,
**Odoo 19.0+e, base 19.0.1.3**, 567 встановлених модулів, `web_studio` і `l10n_ua` встановлені,
`web.base.url` збігається. Доступ — XML-RPC з API-ключем; ключ після роботи видалено.
Тестові записи створювались із префіксом `TEST-` і видалені (залишків 0).

Позначки: **є** — штатно; **Studio** — робиться в Studio; **немає** — на Odoo Online не робиться;
**частково** — механізм є, але вужчий за обіцянку.

## Що не вдалося перевірити на пробній базі

- **Банківська синхронізація для українських банків** — перелік інституцій завантажується в майстрі UI з odoofin, через API не видно.
- **SMS-підпис на +380 і вартість IAP** — акаунта `sms` на стенді немає, кредитів 0.
- **Типи дій кнопок Studio** («Run a Server Action» / «Call a method» / «Execute Code») — лише в UI редактора.
- **Мова контрагента в Studio-бланку** — на стенді немає жодного бланка, створеного з нуля в Studio.
- **Конвертація валют у мультикомпанійному звіті** — на стенді одна компанія.
- **Вимога `hr.employee` для таймшитів** — не створював тестового користувача без картки.

## Правки в `data/price.json`

Внесено (тільки формулювання й «не входить», години й економію не чіпав):

- **Склад** р.3: «поля партій і термінів (Studio)» → «терміни придатності партій — штатний модуль Expiration Dates, без Studio»; «не входить»: Combo не замінює набори.
- **Планування** р.2: «планування за проєктами» → «планування за ролями і замовленнями; поля проєкту у зміні на Odoo 19 Online немає».
- **Продажі** р.2, **Документи** р.2: підпис уточнено — «простий підпис із SMS-кодом, не КЕП».
- «Не входить» доповнено: База (ЄДРПОУ без валідації; переклад полів 60–90 %), Магазин (без українського еквайрингу й перевізників), POS (без ПРРО), Управлінський облік (фіскальних позицій немає), Персонал (payroll UA немає), Друковані форми (сума прописом змішує мови).

П'ять пунктів, які я збирався переформулювати (ліміти витрат, аванси, карта FSM, квоти CRM, маршрути Документів), у гілці аналізу вже були сформульовані точніше за моє — стенд їх підтвердив, тексти лишено.
